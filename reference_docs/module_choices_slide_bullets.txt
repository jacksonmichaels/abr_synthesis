========================================================================
Techniques - Adversarial Lineage Decoupling
diagram: adversarial_lineage_decoupling.svg
========================================================================
Description:
- second head predicts lineage off the shared latent
- its gradient is sign-flipped (reversal layer) so the latent becomes
  lineage-agnostic
Notes:
- directly targets the known shortcut: models over-rely on lineage as a
  confounder
- keeps the ABR signal, removes population-structure signal


========================================================================
Techniques - Predict MIC and ABR (Multi-Task)
diagram: mic_abr_multitask.svg
========================================================================
Description:
- add a second head predicting MIC (binned / ordinal) alongside binary R/S,
  off the same latent
- forces the latent to organize around mutation severity, not just a
  threshold
Notes:
- MIC labels are sparse and qualitative -> mask the loss when absent
  (still need to confirm availability)


========================================================================
Techniques - Causal Interpretability via Probing
diagram: causal_probing.svg
========================================================================
Description:
- inject canonical ref-alt variant latents into a frozen model, read the
  change in prediction
- gives the causal effect of a variant, vs SHAP which is correlational
Notes:
- diagnostic only, no performance gain
- avoids the common confounder (co-resistance to other drugs)


========================================================================
Techniques - Staged Training with Frozen Encoders
diagram: staged_frozen_training.svg
========================================================================
Description:
- 3 stages: pretrain DNA + protein encoders on sequence -> freeze -> add
  lineage branch, train only the fusion head
- fuses heterogeneous modalities without destabilizing pretrained encoders
Notes:
- cheap way to add lineage late and control its influence
- pairs with modality drop-out
